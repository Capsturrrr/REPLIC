Real C code throughout: the sender is librudp, the receiver is bin/server, and the network is bin/impair, a UDP proxy that adds delay, jitter, random loss and a drop-tail bottleneck. Transfers run one after another so they do not disturb each other. Kernel TCP is not in this race because it cannot run through a UDP proxy; see the netem results in the report for that comparison.
