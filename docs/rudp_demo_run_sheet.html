Network in Packet Tracer

2 minCisco Packet Tracer
  1. R2: neighbours
    show ip ospf neighbor
    Three neighbours in FULL state
  2. Student PC: trace the route
    tracert 192.168.30.10
  3. Student PC: ACL check
    ping 192.168.20.11
    Fails by design (students blocked from staff VLAN 20)
  4. Student PC: start a continuous ping
    ping -t 192.168.30.10
  5. R1: break the link
    enable
configure terminal
interface gigabitEthernet 0/2
shutdown
    Run tracert again: the path now goes via R2
  6. R1: restore the link
    no shutdown
    Same interface context as the step above
ExpectRouting converges, the ACL blocks staff VLAN, and a link failure reroutes through R2 with about 70 of 71 pings getting through.
SayPacket Tracer cannot run our C programs, so the protocol and the network are validated separately.

Wireshark

1 minWindows or WSL with Wireshark
  1. Open the supplied trace with our dissector
    wireshark -X lua_script:network/rudp.lua network/smart_lossy_aimd.pcap
  2. Filter for data segments
    smartrudp.flags.data == 1
  3. Show retransmissions: pick a sequence number with several copies
    smartrudp.seq == <number>
  4. Optional: capture your own on WSL loopback
    sudo tshark -i lo -f "udp port 8888" -w rudp_real.pcap
    Then run ./bin/server and ./bin/client 20; copy the file to Windows
ExpectPackets decode as RUDP with seq, ack, flags and CRC. Several copies of one seq show a retransmission.
SayIf packets show as plain UDP: Analyze > Decode As > UDP port 8888 > RUDP. Windows Wireshark cannot see the WSL loopback.

Backup plan and limits

  • If a live demo misbehaves, show the make test output and Section 8 of the report: they hold the same evidence.
  • If a port is busy: pkill -x server (never pkill -f in your own shell).
  • Windows cannot capture the WSL loopback: use tshark -i lo inside WSL, or open the supplied .pcap files.
  • Say these limits before you are asked: kernel TCP is still 1.5x to 1.7x faster than the neural agent; against tuned AIMD the agent takes about 70% of a shared link; no gain at 10% random loss; the two-machine run was one drifting relay path.
