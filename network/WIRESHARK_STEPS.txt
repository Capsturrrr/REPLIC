Wireshark steps for the RUDP / Poise trace
================================================
A. Open the supplied traces (no setup needed besides the dissector)
   1. Copy rudp.lua to Wireshark's personal plugin folder (Help > About Wireshark > Folders > Personal Lua Plugins) and restart Wireshark.
      Or run:  wireshark -X lua_script:rudp.lua smart_lossy_aimd.pcap
   2. File > Open smart_lossy_aimd.pcap  (and smart_lossy_rl.pcap).
   3. If packets show as plain UDP: Analyze > Decode As... > UDP port 8888 -> RUDP.
   4. Filters:  smartrudp.flags.data == 1      (data segments)
                smartrudp.flags.ack == 1       (acknowledgments)
                smartrudp.seq == <number>      (every copy of one packet = retransmissions)
   5. Statistics > I/O Graphs for rate over time.
   NOTE: these .pcap files are written by smart_client --pcap. They are a receiver-side record of the packets that
   survived the emulated path, wrapped in synthetic IP/UDP headers (192.168.10.10 <-> 192.168.30.10). The 3-way handshake is not included.

B. Capture your own on WSL (real packets on the loopback interface)
   sudo tshark -i lo -f "udp port 8888" -w rudp_real.pcap      # terminal 1
   ./bin/server   and   ./bin/client 20                          # terminals 2 and 3
   Copy rudp_real.pcap to Windows and open it in Wireshark (Windows Wireshark cannot see the WSL loopback).

C. In Cisco Packet Tracer (Simulation mode)
   Event List Filters: OSPF, DHCP, ICMP, UDP. Add Complex PDU: PC-Student -> 192.168.30.10, UDP, source/dest port 8888.
   Click a packet in the Event List to open the PDU details (layers 2-4). Packet Tracer cannot be captured by Wireshark;
   use Simulation mode screenshots for that part of the demo.
